# Repository audit records

This directory contains repository-wide audit and assessment snapshots. These are historical records, not automatically current policy.

- [Repository engineering audit](repository-engineering-audit.md) — engineering/repository assessment; use its recorded baseline commit and observation date when interpreting findings.

For new audits, follow [Documentation Governance](../DOCUMENTATION_GOVERNANCE.md#8-audits-investigations-and-evidence). Preserve source commit, scope, provenance, confidence, limitations and follow-up links. Do not silently rewrite an earlier audit; add a dated addendum or successor assessment.
